# Your first hour

Takumi is built so that one hour is enough. This page follows that hour in
the order things usually come up, with the keys you know from a Mac or a
Windows PC beside Takumi's. `Super` is the key with the Windows logo, or
Command on a Mac keyboard. Nothing here needs a terminal.

## Get online

Click the marks at the right of the capsule at the bottom of the screen, or
press `Super+I`: that is Quick settings. The arrow on Wi-Fi lists networks.
Pick yours, press Enter and type its password right there; a wrong one is
known in seconds. A hotel or café page that wants you to sign in opens by
itself. Later, Enter on your own network shows a code a visitor's phone
camera can scan to join.

| | Mac | Windows | Takumi |
|---|---|---|---|
| Wi-Fi, Bluetooth, sound | Control Center | Quick Settings (`Win+A`) | `Super+I`, or click the marks |
| Give a guest the Wi-Fi | share from a nearby iPhone | read the password out | Enter on your network: a code to scan |

The arrow on Bluetooth finds your headphones and pairs them, checking the
code the way a phone does.

## Find anything

`Super+Space` grows the capsule into the Palette. Type part of a name and
press Enter: an app (`fire` is Firefox), an open window, a setting
(`bluetooth`), a sum, or a sentence such as "turn off bluetooth and dim the
screen".

When you do not know the word, Enter on **Settings** in the empty Palette
lists the topics: Wi-Fi, Bluetooth, Sound, Displays, Keyboard & mouse, Power
& battery, Look, Apps, Privacy & security, Backups. Enter on one shows
everything about it. **Help** opens this guide in the browser.

| | Mac | Windows | Takumi |
|---|---|---|---|
| Open an app or a setting | `Cmd+Space`, then type | `Win`, then type | `Super+Space`, then type |
| Browse the settings | System Settings | Settings | **Settings** in the empty Palette |
| Browser, files, terminal | the Dock | the taskbar | `Super+B`, `Super+E`, `Super+Return` |
| What is using the computer | Activity Monitor | Task Manager | `Super+Space`, type `btop` |

## Get your apps

Type the app's name in the Palette. When you do not have it yet, the row says
"Get Spotify" (or Zoom, Slack, Steam and many more): Enter installs it from
Flathub, just for you, without a password.

| | Mac | Windows | Takumi |
|---|---|---|---|
| Get an app | App Store | Microsoft Store | `Super+Space`, its name, Enter on "Get …" |

## The keys your hands know

`Super` is Command. `Super+C`, `V`, `X`, `Z`, `A`, `S`, `F`, `W`, `T` and `N`
mean the same thing in every app, the terminal included. If you came from
Windows, `Ctrl` still works in most apps; `Super` works in all of them.

| | Mac | Windows | Takumi |
|---|---|---|---|
| Copy, paste, cut, undo | `Cmd+C` `V` `X` `Z` | `Ctrl+C` `V` `X` `Z` | `Super+C` `V` `X` `Z` |
| Everything you copied | a clipboard app | `Win+V` | `Super+P`; Enter pastes it |
| Emoji | `Ctrl+Cmd+Space` | `Win+.` | `Super+.`; type a name, Enter types it |
| Close a tab, the window | `Cmd+W`, `Cmd+Q` | `Ctrl+W`, `Alt+F4` | `Super+W`, `Super+Q` |

## Windows sit side by side

Windows open next to each other on an endless strip and never cover one
another. Opening one never shrinks the one you were reading; you slide along
the strip instead.

| | Mac | Windows | Takumi |
|---|---|---|---|
| Go to another window | `Cmd+Tab` | `Alt+Tab` | `Super+Tab` for the last one, `Super+←` `→` along the strip |
| See everything | Mission Control | Task View | `Super+O` |
| Another desktop | `Ctrl+←` `→` | `Win+Ctrl+←` `→` | `Super+↑` `↓`, or `Super+1` to `9` |
| Make a window wider | drag its edge | `Win+Arrows` | `Super+R` steps the width, `Super+M` fills the screen |

## Screenshots and recording

The picture shows in the capsule, and a press opens it.

| | Mac | Windows | Takumi |
|---|---|---|---|
| The screen, a part, a window | `Cmd+Shift+3`, `4`, `5` | `Win+Shift+S` | `Super+Shift+3`, `4`, `5` (`Super+Shift+S` for a part) |
| Record the screen | `Cmd+Shift+5` | Snipping Tool | `Super+Shift+6`, again to stop |
| Pick a colour, copy text off the screen | Digital Color Meter, Live Text | PowerToys | Colour and Text in Quick settings |

## Make it yours

`Super+Space`, type `theme`, and move up and down: each of the fifty-five
themes shows itself on the shell before you choose. Enter keeps one, Esc puts
yours back. A theme follows the time of day by itself, warmer at dawn and
dimmer at night.

| | Mac | Windows | Takumi |
|---|---|---|---|
| Dark mode | Appearance | Personalisation | pick a dark theme (most are); `takumi phase set night` keeps the night colours, `takumi phase set auto` follows the clock again |
| Warmer screen at night | Night Shift | Night light | Night light in Quick settings |
| Quiet notifications | Focus | Do not disturb | Do not disturb in Quick settings |
| Calendar | the menu bar clock | the taskbar clock | click the time in the capsule: Today |

## When something is wrong

`Super+Space`, type `something is wrong`. Takumi checks Wi-Fi, sound, space
and updates, fixes what is safe, and says what it did in one sentence.

## Updates, and the undo button

`Super+Space`, type `update`. Takumi asks once, prepares the new system in a
room beside yours and says when a restart will use it; the one you are using
is not touched. If the new one does not start, the computer comes back to this
one by itself, and "Go back to the previous system" in the Palette undoes an
update you do not like.

| | Mac | Windows | Takumi |
|---|---|---|---|
| Update | Software Update | Windows Update | `update` in the Palette, when you choose |
| Undo an update | Time Machine | System Restore | "Go back to the previous system"; `takumi room list` shows each one you can go back to |
| Shut down, restart, sleep, lock | the Apple menu | the Start menu | type `shut down`, `restart` or `sleep` in the Palette; `Super+L` locks |
| Start over, or give it away | Erase All Content and Settings | Reset this PC | **Erase this computer** in the Palette ([what it erases](installing.md#erasing-a-computer-to-start-again)) |

## What feels different for a week

Windows do not float, there is no menu bar, dock or taskbar (the capsule shows
where you are and what is on), and an app comes from a row in the Palette, not
a downloaded installer. What feels better on day one: nothing phones home,
nothing restarts your computer while you work, and the fans stay quiet.
