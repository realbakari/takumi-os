# The Takumi guide

For people arriving from a Mac or a Windows PC. Every page is something you
can do without a terminal; where a `takumi` command is shown, the same thing
is a row in the Palette (`Super+Space`).

- [Installing Takumi](installing.md): the USB stick, the five questions,
  the recovery code, setting a computer up for someone else, and erasing
  one to start again.
- [Your first hour](your-first-hour.md): getting online, finding things and
  getting your apps, the keys your hands already know, windows on the strip,
  screenshots, making it yours, and the undo button for updates.

The empty Palette has two rows for finding your way: **Settings**, which
lists the topics (Wi-Fi, Sound, Displays…) when you do not know the word to
type, and **Help**, which opens this guide.

How Takumi works inside, for people changing it, is in the `docs/` folder of
Takumi's source.
